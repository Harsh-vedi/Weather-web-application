# 🌦️ Weather App

A modern and responsive **Weather Application** built using **HTML, CSS, and JavaScript**, integrated with the **OpenWeatherMap API** to fetch real-time weather data based on city name.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡 Displays current temperature, humidity, and wind speed  
- ☁️ Dynamic weather icons and condition descriptions  
- 🎨 Responsive card-based UI design  
- 🌈 Automatic background color change based on weather type  
- 🔐 Fetches live data from OpenWeatherMap API  

---

## 🧰 Technologies Used

- **HTML5** – Structure of the app  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Logic and API integration  
- **OpenWeatherMap API** – Weather data source
